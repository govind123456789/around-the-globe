{{ site.name }} is a free, open platform for ranking and comparing countries. It aims to make it easy to go from a number, to a ranking, to an explanation, and to check every step along the way.

## What makes it different

- **Every number is traceable.** Each value shows its source, the year it describes and its licence. Each score links to the formula and the weights that produced it.
- **Official and original are kept apart.** Official indices such as UNDP's Human Development Index are shown exactly as published. The platform's own indices are clearly labelled as its own.
- **Uncertainty is shown, not hidden.** Original indices publish a rank range from a sensitivity analysis. Countries without enough data are marked "not ranked", never filled in with zeros.
- **Open by default.** All data can be downloaded and reused under CC BY 4.0, and the code is open source.
- **Free for everyone.** There is no paywall, no account and no advertising.

## How it works

The site is rebuilt from source data on a schedule. A pipeline downloads data from the World Bank and UNDP, validates it, checks every source's licence, calculates the rankings and writes a dated data release. The website is a set of static pages built from that release. No server computes anything when you visit.
