Open data API

The API is a set of static JSON files at stable URLs: the same files this website reads. There is no key and no rate limit, and cross-origin requests are allowed.

Use /v1/latest/… for the newest release, or /v1/releases/{date}/… for a fixed, unchanging release. releases.json lists all releases.

PathContents
/v1/latest/manifest.jsonFiles, checksums, source retrieval dates
/v1/latest/sources.jsonSources, licences, attribution text
/v1/latest/entities/country.jsonAll countries
/v1/latest/entities/country/{ISO3}.jsonOne country: latest values with provenance, full series, percentiles, rankings
/v1/latest/indicators.jsonIndicator catalogue
/v1/latest/indicators/{id}.jsonOne indicator, all countries and years
/v1/latest/rankings.jsonAll rankings and versions
/v1/latest/rankings/{id}/{version}.jsonDefinition, weights and results (immutable per version)
/v1/latest/matrix.jsonCompact country × indicator matrix (used by the Index Builder)
/v1/latest/bulk/{table}.{csv.gz|parquet}Bulk tables (CSV is gzip-compressed)

Example

const r = await fetch("{{ site.base_url }}/v1/latest/entities/country/IND.json");
const india = await r.json();
india.latest["life-expectancy"];
// → { kind: "observed", value: …, year: …, status: "measured",
//     source: "wb-wdi", source_licence: "CC BY 4.0", retrieved_at: "…" }

Every observed value carries value, year (the year the data describes), status (measured or estimate), source, source_licence, source_url and retrieved_at. Missing data is left out, never returned as 0.

The full OpenAPI description is in the project repository (docs/05-openapi.yaml). An AI assistant endpoint and an MCP server are planned for months 5–6.
