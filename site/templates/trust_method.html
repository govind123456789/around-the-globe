Methodology

How trust levels work

Every value on this site carries a trust level: High, Medium or Low. It is not a judgement of the publisher. It says how far you can lean on that one number today: how old it is, what kind of source made it, and whether the source calls it an estimate. This page is generated from the same settings file the code uses (data/trust.yaml).

Points

A value starts at zero points and gains points for each concern below. Then:

  • {{ trust_cfg.levels.high.icon }} {{ trust_cfg.levels.high.label }}: {{ trust_cfg.levels.high.max_points }} points.
  • {{ trust_cfg.levels.medium.icon }} {{ trust_cfg.levels.medium.label }}: {{ trust_cfg.levels.high.max_points + 1 }} to {{ trust_cfg.levels.medium.max_points }} points.
  • {{ trust_cfg.levels.low.icon }} {{ trust_cfg.levels.low.label }}: {{ trust_cfg.levels.medium.max_points + 1 }} points or more, or a value far older than its source usually is (below).

Age

Each source publishes with a usual delay (its lag): most international series describe the year before last. A value counts from the release year ({{ release[:4] }}):

  • Up to {{ trust_cfg.freshness.aging_after }} year{{ 's' if trust_cfg.freshness.aging_after != 1 }} beyond the source’s lag: no points.
  • More than {{ trust_cfg.freshness.aging_after }} beyond the lag: 1 point.
  • More than {{ trust_cfg.freshness.old_after }} years beyond the lag: Low, whatever the other points.
