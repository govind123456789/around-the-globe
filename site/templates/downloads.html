Every release is kept. Each weekly release is archived as a GitHub Release, so links of the form {{ site.base_url }}/v1/releases/{{ release }}/bulk/observations.parquet keep working after later updates. Cite the dated link, not /v1/latest/. Each archive also holds the full JSON API as api-json-<date>.zip.

CSV files are gzip-compressed (.csv.gz); most spreadsheet tools, pandas and R read them directly, or unzip them first.

Query the Parquet files directly

-- DuckDB
SELECT entity_id, year, value
FROM '{{ site.base_url }}/v1/releases/{{ release }}/bulk/observations.parquet'
WHERE indicator_id = 'life-expectancy' AND entity_id IN ('IND', 'CHN')
ORDER BY year;

How to cite: “{{ site.name }}, data release {{ release }}, CC BY 4.0, {{ site.base_url }}/data/downloads/”. Please also credit the original sources listed in ATTRIBUTION.md.
