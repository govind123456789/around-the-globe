How it is built

    {% for k, label, w in weights %}

    2. {% endfor %}

Each measure is scaled 0–100 across countries (conflict and displacement on a log scale, so a few extreme cases don’t flatten the rest), then weighted. Countries need conflict, instability and at least one other measure; a missing measure’s weight is shared among the others. The index is calculated for every year since {{ risk_from }} on one common scale, so scores can be compared over time; it uses only verified datasets, not news coverage. Bands: low under 25, elevated 25–40, high 40–55, very high 55+.
