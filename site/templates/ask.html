Ask the data Coming months 5–6

An AI assistant that answers questions using only this site’s data. Every figure it gives will come from a lookup against the published release, with a citation. It will never make up numbers.

Until then

Use Compare for side-by-side questions, the Index Builder for “which country is best for…” questions, and Explore for “where is X highest” questions.

How it will work

It will use a short daily question allowance, with a bot check and a daily spending cap. Repeat questions will be answered from a cache. You will be able to use your own API key for more questions; the key will stay in your browser.
